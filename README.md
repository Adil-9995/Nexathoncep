# Nexathon — Campus Peer Learning & Textbook Exchange

Nexathon is a student-powered circular platform where students learn directly from one another with zero course tuition, share knowledge, and buy or sell second-hand textbooks with community credit rewards.

---

## Key Features

- **Peer-to-Peer Learning**: Connect with fellow students to learn skills like Figma, Flutter, Django, and Java 1-on-1 for ₹0 tuition.
- **Credit Wallet System**:
  - Request a session: **-2 Credits** deducted from the learner.
  - Complete a teaching session: **+5 Credits** awarded to the mentor.
  - Textbook transactions: **+2 Credits** bonus awarded to both buyer and seller.
- **Second-Hand Book Marketplace**: Browse and sell affordable course textbooks with a flat 2% campus platform fee.
- **Instant Interactive Feedback**: Real-time animated balance alerts and celebration notifications for credit adjustments.
- **Responsive Web Design**: Clean, modern interface optimized for mobile and desktop screens.

---

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Vanilla CSS Design System, Lucide Icons
- **Effects & UI**: Canvas Confetti, Glassmorphism, Google Fonts (Outfit & Inter)
- **Backend Ready**: PostgreSQL schema (`supabase_schema.sql`) for optional Supabase cloud integration

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/nexathon.git

# Navigate into the project directory
cd nexathon

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be live at `http://localhost:5173`.

### Production Build

```bash
npm run build
```
